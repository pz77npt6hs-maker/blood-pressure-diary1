# 혈압 다이어리 PWA

## 기능
- 아침/저녁 각각 2회 혈압·맥박 입력
- 시간대별 2회 평균 자동 계산
- 아침 평균과 저녁 평균을 바탕으로 하루 평균 계산
- 키 입력, 체중 기록, BMI 자동 계산
- 음주/금주 체크
- 월간 달력에서 기록한 날짜 표시 및 날짜별 기록 확인
- 달력 날짜를 눌러 해당 날짜 기록 입력
- 혈압 및 체중 그래프
- CSV 내보내기
- 브라우저 로컬 저장

## iPhone에서 사용하는 방법
이 파일을 아이폰에서 바로 앱스토어 앱처럼 설치하는 것은 아니며, 홈 화면 설치를 위해 HTTPS 주소로 배포해야 합니다.
1. ZIP 압축을 풉니다.
2. `index.html`, `manifest.webmanifest`, `sw.js` 세 파일을 GitHub Pages 등 HTTPS 정적 호스팅에 올립니다.
3. 아이폰 Safari에서 배포된 주소를 엽니다.
4. 공유 버튼 → '홈 화면에 추가' → '웹 앱으로 열기' 옵션이 보이면 켭니다 → 추가.

## 데이터 주의
- 기록은 해당 iPhone의 Safari 사이트 저장공간에만 보관됩니다.
- 브라우저 데이터 삭제, 기기 변경 시 기록이 사라질 수 있으므로 주기적으로 CSV 내보내기를 권장합니다.
- 서버나 계정으로 동기화하지 않습니다.
- BMI는 키와 체중으로 계산한 참고 지표이며 건강상태를 진단하지 않습니다.
- 혈압은 시간대별 평균과 하루 평균을 참고용으로 표시합니다. 진단·치료 판단은 의료진과 상의하세요.
